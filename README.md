# 로또 1등 시뮬레이션

매주 100장씩 6/45 로또를 구매했을 때, 1등에 당첨되기까지 **몇 주**가 걸리는지 보여주는 웹 시뮬레이션입니다. 기본 속도는 **0.1초에 1주**이며, 1등이 나오는 순간 자동으로 멈춥니다.

Next.js(App Router) + React + TypeScript로 만들었고, 별도 서버나 데이터베이스 없이 정적 페이지로 동작합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 엽니다.

프로덕션 빌드:

```bash
npm run build
npm start
```

## 속도

| 모드 | 속도 | 평균 81,451주 소요 |
| --- | --- | --- |
| `0.1초/주` | 10주/초 | 약 2시간 15분 |
| `0.02초/주` | 50주/초 | 약 27분 |
| `500주/초` | 500주/초 | 약 2분 43초 |
| `8,000주/초` | 8,000주/초 | 약 10초 |

`결과까지 바로` 버튼을 누르면 터보 모드로 전환됩니다. 화면의 주차 카운터와 티켓 그리드는 실제 구매·추첨 과정을 매주 시뮬레이션한 결과입니다.

## 시뮬레이션 규칙

- 1주에 100장, 장당 1,000원 (주 10만원)
- 6/45 추첨: 당첨 번호 6개 + 보너스 번호 1개
- 1등 6개, 2등 5개+보너스, 3등 5개, 4등 4개, 5등 3개 일치
- 1등 확률은 장당 1/8,145,060, 100장 기준 기대 소요는 약 81,451주(약 1,561년)
- 1등 당첨금은 평균 20억원으로 가정

## 구조

```
app/
  layout.tsx     메타데이터 · 전역 스타일
  page.tsx       시뮬레이터 렌더링
  globals.css    디자인 시스템 · 반응형 스타일
  icon.svg       파비콘
components/
  Simulator.tsx  UI · 재생/일시정지/속도 제어 · 결과 모달
lib/
  lotto.ts       난수 · 티켓 생성 · 당첨 판정 · 확률 계산
```

시뮬레이션은 `mulberry32` 기반의 시드 가능한 난수를 사용합니다. 1등 당첨 시 해당 주차의 100장 티켓 배치까지 화면에 유지됩니다.

> 오락용 시뮬레이션입니다. 실제 추첨 결과와 무관하며, 당첨을 보장하지 않습니다.
